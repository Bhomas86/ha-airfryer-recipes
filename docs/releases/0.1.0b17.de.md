# 0.1.0b17 – Darstellungsoptionen im Karteneditor

[Deutsch](0.1.0b17.de.md) | [English](0.1.0b17.md)

Der grafische Karteneditor bietet kompakt/normal/groß, eine unabhängig einstellbare Gerätegrafik (klein/normal/groß) und Schalter für Status sowie „Zuletzt gesendet“. Bestehende Cards behalten ihre bisherige Darstellung. Ausblenden löscht keine Historie und hebt keine Sende-/Offline-/Berechtigungsprüfung auf. Warnungen und Bestätigung bleiben sichtbar. Darstellungswechsel verwerfen vorbereitete Sendebestätigungen wie bisher; es wird nichts automatisch gesendet.

b17 über HACS installieren, HA neu starten und die App neu laden. Im Dashboard die Card bearbeiten und die Darstellungsoptionen wählen. Testmodus aktiviert lassen: Größe wechseln, Status/Historie aus- und einschalten, Fachwerte vergleichen. Dafür keine Geräteübertragung nötig. Bilder-Uploads und frei verschiebbare Fachpositionen bleiben ein separates Paket.

Am 03.11.2026 hat der Eigentümer die drei lokalen b16-Rechteprüfungen bestätigt: ohne Freigabe kein Gerät, nach Freigabe beide Fächer nutzbar, nach Entzug kein Gerät. Daraus folgt keine zusätzliche Abnahme von Rechte-Neustart oder Entzug während einer realen Übertragung.

Lokal geprüft: 203 Python- und 98 Frontend-Tests, Kompilierung, Dokulinks/Sprachpaare und Formatprüfung. Neue native Darstellungsoptionen noch nicht lokal abgenommen; HACS/Hassfest und Python 3.14 nicht ausgeführt. Keine GitHub Actions. Nur die neue Beta bleibt nach geprüfter Veröffentlichung aktiv; ältere Betas werden Entwürfe, Tags und Code bleiben erhalten.
