# 0.2.0 — Production interface without test tools

[English](0.2.0.md) | [Deutsch](0.2.0.de.md)

Stable versions hide guided appliance tests, device dry-run forms, supervised commissioning controls and their explanatory footer in the recipe library. Normal recipe editing/import/export, device grants, diagnostics and completion settings remain available. Dashboard cards hide the test-mode switch and SYNC/MATCH preview buttons; regular confirmed single-zone and SYNC/MATCH preparation remain.

**Existing `dry_run: true` card configurations are also treated as normal preparation in stable builds.** This follows the owner's request to remove the production test mode. No command is sent automatically: an explicit click and exact confirmation are still required. Backend authorization, fresh-state checks, one-shot transport, no retry/no heating start, and the server-side dry-run APIs are unchanged. No recipe, grant, history or storage migration.

Beta builds (`0.2.0b1` / `0.2.0-beta.1` style versions) expose the test tools again and default cards to test mode. Stable `0.2.0` hides them through the release-channel flag. Frontend module/cache versions match the manifest.

Install v0.2.0 in HACS, restart HA and fully reopen Companion/browser. No dashboard edit should be necessary. Review device settings before deliberately sending as usual. Supported model/controller versions are unchanged from 0.1.0.

Validation: 291 Python tests and 140 frontend tests passed locally. Stable/beta rendering, release-channel recognition, normal confirmed controls and hidden editor/test options are covered. Python compilation and `git diff --check` passed. GitHub Actions remain paused under the repository instructions; no new real appliance tests were performed.
