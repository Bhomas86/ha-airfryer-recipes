# 0.1.0b13 – Neutrale Dashboard-Card mit getrennter Fachhistorie

[Deutsch](0.1.0b13.de.md) | [English](0.1.0b13.md)

Der freigegebene Entwurf 1A ist als mitgelieferte Home-Assistant-Dashboard-Card umgesetzt: eigene neutrale Grafik mit gestapelten Schubladen, antippbare Fächer, Rezept-/Manuell-Werte, Programmauswahl, Temperatur und Dauer. Der grafische Editor unterstützt Titel, optionale Geräte-ID und Testmodus. **Zuletzt gesendet** zeigt Programm/Temperatur/Dauer der letzten vom Adapter angenommenen Übertragung getrennt je Gerät/Fach und über Neustarts hinweg. Fachwechsel senden nichts; Formulareingaben lassen diese Anzeige unverändert. Bestehende Rezepte bleiben erhalten.

Backup erstellen, `v0.1.0b13` in HACS installieren, HA neu starten und die App vollständig neu öffnen. Dashboard → Bearbeiten → Karte hinzufügen → **Airfryer Recipes**. Die Integration lädt das Modul automatisch. YAML-Alternative:

```yaml
type: custom:airfryer-recipes-card
title: Airfryer Küche
dry_run: true
```

**Testmodus ist voreingestellt und sendet keinen Gerätebefehl.** Ausschalten verwendet den vorhandenen beaufsichtigten Beta-Sendeweg ausschließlich für Administratoren mit einer Bestätigung der exakten Werte. Start bleibt am Gerät. Zuletzt gesendet bedeutet Adapterannahme, keinen aktuellen Gerätezustand oder Gerätebestätigung; Übertragungen vor diesem Update werden nicht rekonstruiert. Geräteberechtigungen für normale Benutzer bleiben geplant. Keine erweiterten Temperaturgrenzen oder Unterstützung für Gären; vorhandene Adapter-/Modell-/Zustandsprüfungen bleiben bestehen.

Lokal bestanden: **170 Python- und 80 Frontend-Tests** (59 Panel, 21 Card), Kompilierung und Formatprüfung. Dokumentation und lokale Abnahme: [Dashboard-Bericht](../reports/ISSUE_8_DASHBOARD_CARD.de.md). Native HA-/Companion-Darstellung, neue Geräteabnahme, HACS/Hassfest und Python 3.14 wurden nicht ausgeführt. Keine GitHub Actions gestartet.
