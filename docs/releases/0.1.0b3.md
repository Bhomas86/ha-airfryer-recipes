# 0.1.0b3 – Supervised interface test

[Deutsch](0.1.0b3.de.md) | [English](0.1.0b3.md)

**Experimental prerelease for local appliance acceptance. No general approval of device control.**

A separate administrator section, “Supervised beta device test”, prepares fixed **Air Fry, 170 °C, one minute** settings for **CAF-DC111S-AEU**, zone **1 or 2** only. “Send once to the appliance” plus a confirmation dialog is required for a real attempt. The existing device preview remains free of control commands.

Requires exactly **Airfryer Control 1.0.2-beta.1**, whose public program service was reviewed. Both zones must be reported and idle/off, Celsius selected and SYNC/MATCH off. The successful device report must be at most 15 seconds old. Any new report, state change or adapter reload invalidates the 15-second single-use confirmation.

The backend sends one fixed variant with `einmal=true`, `streng=true` and without automatic device confirmation. No automatic retry, queue, zone-0, start, SYNC or MATCH variant. Unknown outcomes block further beta attempts for that device until a complete HA restart; integration reload does not clear the block. Adapter acceptance explicitly does **not** confirm the device.

Cosori programs and limits remain unverified. The owner authorized this exception for an explicitly confirmed, supervised initial test on 2026-10-30. Free values, other programs including `proof`, normal-user control and the dashboard are not approved. Appliance acceptance: **NOT TESTED**.

## Installation and test

1. Back up HA. Retain/install Airfryer Control **1.0.2-beta.1**.
2. Show prereleases in HACS and redownload Airfryer Recipes as **v0.1.0b3**. Fully restart Home Assistant, close and reopen the Companion app.
3. Follow the [test procedure](../reports/ISSUE_7_BETA_SEND.md#local-appliance-acceptance). Remain beside the empty appliance and **do not press Start**. If heating starts or the other zone changes, stop at the appliance and perform no further tests.

Passed locally: **101 Python tests**, **20 frontend tests**, compilation and `git diff --check`. The single full GitHub acceptance run is requested through the PR's `[full-ci]` marker. No real appliance/HA tests were executed. See the [implementation report](../reports/ISSUE_7_BETA_SEND.md) for details and remaining limits.
