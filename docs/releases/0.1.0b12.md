# 0.1.0b12 – Program selection in the recipe editor

[Deutsch](0.1.0b12.de.md) | [English](0.1.0b12.md)

The recipe editor now offers a dropdown of programs reported by the selected air fryer. Translated labels save the exact adapter identifier, such as `airfry`. Estimated/unverified programs remain marked. A custom-input switch and the no-adapter text fallback keep recipes independent of any appliance.

Existing identifiers are preserved until explicitly changed and saved. For example, a stored `Airfry` differs from the reported `airfry`; the preview now offers “Edit recipe program” when the selected recipe uses an unreported identifier. Opening or refreshing the editor does not fix recipes automatically. Draft fields survive program/mode changes and refreshes.

Back up, select v0.1.0b12 in HACS, restart HA and fully reopen the app. Select the air fryer, choose Piccolinies and use “Edit recipe program” or its normal Edit button. In the recipe editor choose Air Fry / Heißluft-Frittieren from the dropdown, retain 180 °C / 7 minutes and save. The device preview should now show the reported program.
