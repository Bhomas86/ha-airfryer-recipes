# 0.1.0b26 – Own guarded SYNC/MATCH sender

[Deutsch](0.1.0b26.de.md) | [English](0.1.0b26.md)

Test beta from PR #48. Since the last published b23, this also includes diagnostic preview/download and opt-in Companion completion notices from #10. Native acceptance remains pending; this is not a stable release.

SYNC and MATCH use our own guarded sender without modifying the controller. Both zone reports, grants, fresh state, recipe values and one-use confirmation are checked after any required login, immediately before device submission. Missing, unknown, active, prepared, offline or stale zones block. No resets, automatic retries or requested heating start. After an unknown outcome, inspect/clear both zones physically and explicitly request read-only re-arm.

Combined preparation requires exactly Airfryer Control **1.0.3 or 1.0.4-beta.1** and CAF-DC111S-AEU. Transport is coupled to these reviewed controller internals. Single-zone sends/completion notices additionally support previous 1.0.3-beta.3. Other devices can still manage recipes; this does not grant transmission permission.

Passed locally: **285 Python tests on 3.12.14, 135 frontend tests**, compilation, language/documentation and formatting checks. Python 3.14 is absent from this runtime; no renewed 3.14 run. No new GitHub Actions or real appliance/cloud/push tests. Official final checks and native acceptance remain required before stable. Existing recipes, device grants and history are preserved; no schema migration.

## Installation and acceptance

1. Show beta versions in HACS, install **v0.1.0b26**, restart Home Assistant and fully reopen the Companion app. Start with card test mode enabled. No dashboard is changed automatically.
2. Set different values in both zones. Check SYNC/MATCH previews: no appliance change. MATCH must display zone 1 settings for both zones.
3. Supervised settings-only check: physically clear both zones and combined mode. Disable test mode, prepare SYNC, review both exact values and confirm once. **Do not press Start.** Check reported settings/mode; heating must not start. Physically cancel prepared programs. Repeat for MATCH, then cancel again.
4. Check a canceled confirmation and revoked whole-device grant: no send. Verify independent zone controls and last sent settings.
5. Recipe library → Diagnostics and completion notices: preview/download JSON and inspect privacy. Notices default off. Configure the desired zone and Companion destination; the rule must survive HA restart. During an ordinary supervised cooking cycle started physically, check exactly one completion notice. No empty-appliance heating test is required. Cancellation/offline/restart while already finished must not produce false notices.
