# 0.1.0b17 – Display options in the visual card editor

[Deutsch](0.1.0b17.de.md) | [English](0.1.0b17.md)

The visual editor offers compact/normal/large card sizes, independent small/normal/large appliance graphics and switches for status and Last sent. Existing cards retain their approved appearance. Hiding information does not delete history or bypass send/offline/permission checks. Warnings and confirmation remain visible. Appearance changes invalidate prepared confirmations as before; nothing is sent automatically.

Install b17 through HACS, restart HA and reload the app. Edit the dashboard card and choose display options. Keep test mode enabled: change size, hide/show status/history and compare zone drafts. No appliance transmission is needed. Image uploads and draggable zone positions remain a separate package.
