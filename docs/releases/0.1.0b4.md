# 0.1.0b4 – Refresh status before the beta test

[Deutsch](0.1.0b4.de.md) | [English](0.1.0b4.md)

**Test prerelease, not general approval of device control.**

In 0.1.0b3, “Prepare real device test” could fail on an old status report even with the appliance powered on and idle. Preparation only waited for regular reports and requested no new query. The owner's reported attempt was blocked before sending; no arriving appliance command was observed.

Version 0.1.0b4 requests one read-only status refresh through Home Assistant's `homeassistant.update_entity` for a loaded Airfryer Control sensor during preparation. The request receives the authenticated administrator context and has a 20-second timeout. Only a new successful device report can unlock preparation. Old data, query errors and missing sensors remain blocked with distinct guidance. The interface shows “Requesting a fresh device status…” while waiting.

The 15-second bounds for reports and single-use confirmations remain unchanged. Final confirmation does not initiate another refresh that would replace the bound report. The real attempt remains limited to CAF-DC111S-AEU, zone 1/2, Air Fry at 170 °C for one minute. No heating start requested, retries or automatic device confirmation. The existing preview remains free of control commands.

## Installation and repeat test

Back up HA. Continue using exactly Airfryer Control **1.0.2-beta.1**. Redownload Airfryer Recipes as **v0.1.0b4** in HACS, restart HA, then fully close and reopen the Companion app.

As an administrator, select the appliance and zone 1. Both zones must be idle/off, closed, without prepared programs, Celsius selected and SYNC/MATCH off. Select “Prepare real device test” and await the status query. Only after the exact settings confirmation appears, explicitly send once within 15 seconds. **Remain beside the empty appliance and do not press Start.** Stop testing if heating starts, the wrong zone changes or the outcome is unknown. See the [review report](../reports/ISSUE_7_STATUS_REFRESH.md) for details and feedback.
