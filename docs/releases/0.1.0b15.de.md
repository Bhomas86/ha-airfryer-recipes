# 0.1.0b15 – Dashboard-Ressource automatisch registrieren

[Deutsch](0.1.0b15.de.md) | [English](0.1.0b15.md)

Der Eigentümer bestätigt die funktionierende b14-Card nach manuellem Eintragen ihrer JavaScript-Modul-Ressource. Dieses Update legt genau diese Ressource im HA-Storage-Modus automatisch an beziehungsweise aktualisiert sie, unter Erhalt eines vorhandenen manuellen Eintrags und anderer Ressourcen. YAML-Modus behält das Laden als Zusatzmodul. Keine Änderungen an Oberfläche, Rezepten/Historie oder Geräteübertragung.

b15 über HACS installieren, HA neu starten und die App vollständig neu laden. Den funktionierenden manuellen Eintrag behalten; er soll ohne zusätzlichen Eintrag auf `/api/airfryer_recipes/card.js?v=0.1.0b15` aktualisiert werden. Testmodus aktiviert lassen; keine Geräteübertragung nötig. Native Abnahme der automatischen Registrierung bleibt offen. [Umsetzung und Prüfungen](../reports/ISSUE_8_CARD_RESOURCES.de.md).

Auf Eigentümerwunsch bleibt nur die aktuelle Beta veröffentlicht; ältere Betas werden nach Prüfung der neuen Veröffentlichung zu Entwürfen. Tags/Code/Assets bleiben erhalten. Lokal bestanden: **178 Python- und 84 Frontend-Tests**, Kompilierung, Dokumentations- und Formatprüfung. Keine GitHub Actions, HACS/Hassfest, Python 3.14 oder neue Geräteprüfung.
