# 0.1.0b6 – Einmal bestätigen, Testfolge ausführen

[Deutsch](0.1.0b6.de.md) | [English](0.1.0b6.md)

Experimentelle beaufsichtigte Test-Beta. Neu: **„Geführter Gerätetest“** mit maximal zwölf normalen Programmeinstellungen für beide Fächer. Liste anzeigen, einmal vollständig bestätigen; danach nacheinander mit sichtbarem Fortschritt. Keine zusätzliche Bestätigung pro Schritt.

In HACS v0.1.0b6 neu herunterladen, HA neu starten und die App vollständig neu öffnen. Airfryer Control weiterhin exakt 1.0.2-beta.1. Beide Fächer zunächst bereit/aus und ohne Programm; Celsius, SYNC/MATCH aus. Am leeren Gerät bleiben und **nicht Start drücken**. Nach dem Lauf vorbereitete Programme am Gerät abbrechen.

Zwischen Schritten werden frische Rückmeldungen geprüft. Nur eigene, exakt passend zurückgemeldete vorbereitete Werte dürfen überschrieben werden; keine Änderungen aktiver Fächer. „Restliche Schritte abbrechen“ stoppt weitere Befehle, kann aber bereits gesendete nicht zurückholen. Fehler oder Verbindungswechsel stoppen den Lauf ohne Replay. Kein Heizstart, Reset oder Raw-Befehl angefordert.

[Bedienung, Schrittliste und Grenzen](../reports/ISSUE_7_GUIDED_BATCH.de.md). Erweiterte Grenzwert-/Rezepttests bleiben einzeln verfügbar. Reale Geräteabnahme dieser Testfolge steht aus; bei einer Ablehnung oder Abweichung stoppen und den letzten Schritt melden.

Lokal bestanden: 132 Python-Tests, 29 Frontend-Tests, Kompilierung und Formatprüfung. **Keine GitHub Actions gestartet.** HACS/Hassfest, Python 3.14 und echte HA-/Gerätetests nicht ausgeführt.
