# 0.1.0b2 – Device programs from Airfryer Control

[Deutsch](0.1.0b2.de.md) | [English](0.1.0b2.md)

**Prerelease for manual testing. Not a stable release.**

This version extends the device dry-run preview with the public, read-only capability service from Airfryer Control `1.0.2-beta.1`:

- reported programs appear in a dropdown,
- confirmed and estimated limits and confirmed and unverified send status are visibly distinct,
- report time, revision and connection pass through an allowlist only,
- actually reported zones remain separate from the general capability list,
- a saved program not reported by the appliance remains unchanged and is explicitly marked,
- missing, outdated or broken adapter data still does not affect recipe management.

For CAF-DC111S-AEU, currently supplied programs and limits are estimated/unverified. The appliance's visible `proof` program is still absent from the upstream contract. This prerelease therefore continues to enable **no live device transmission**, and dry-run preview executes no control command.

## Installation and verification

Install Airfryer Control `1.0.2-beta.1` or newer first. Then enable beta/prerelease versions for Airfryer Recipes in HACS and use “Redownload” to select `v0.1.0b2`. Restart Home Assistant, fully close the Companion App and reopen it. Create a Home Assistant backup first.

Complete steps are in the [English test guide](../reports/ISSUE_7_DRY_RUN_UI.md). Locally, 78 Python offline tests, 15 frontend tests, Python compilation and `git diff --check` passed. HACS, Hassfest and Python 3.12/3.14 must additionally pass in GitHub Actions before the tag is published.
